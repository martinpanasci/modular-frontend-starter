# Modular Frontend Starter

Este repositorio es un template independiente de frontend. La aplicación npm vive en `client/`.

- Antes de modificar `client/`, leé `client/AGENTS.md` y `client/README.md`.
- Ejecutá instalaciones y checks desde `client/`, no desde la raíz.
- Conservá `.git`, `.github` y la licencia en la raíz; no agregues un paquete npm raíz sin requerimiento.
- Mantené CI, Dependabot y Husky alineados con `client/`.
- No agregues backend ni dependencias del template fullstack.
